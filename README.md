# 艾玛视频 Skills

作者：**王启帆 Emma** · [小红书主页](https://www.xiaohongshu.com/user/profile/5ffd46de000000000101df8b)

**把一场直播或线上课，整理成可以发布的视频、字幕、封面和文案。**

这套 Skills 整理了录播拆选题、口播剪辑、二次剪辑后的字幕校准，以及小红书双图封面的制作方法。可以从总入口连续做，也可以只调用其中一项。

它们是给 AI 助手使用的工作说明和少量辅助脚本。安装 Skill 不等于安装剪辑引擎，也不意味着 AI 已经获得你电脑、图片工具或发布账号的操作能力。

## 按这六步开始

| 顺序 | 你要做什么 | AI / Skills 做什么 |
| --- | --- | --- |
| **1. 开直播或线上课** | 录下分享、演示和问答；保留有权使用的素材 | 这一步主要由你完成，不要求重新写一份标准口播稿 |
| **2. 导出录屏或视频切片** | 保存原录播或已有切片，文件名能分清来源 | 检查素材与版本，避免把重复切片当成新内容 |
| **3. 导出逐字稿** | 可用得到大脑、剪映或已有转写工具导出 TXT / SRT | 有匹配字幕就复用；没有时可用本地转写辅助脚本 |
| **4. 安装 Skills 和剪辑能力** | 安装本仓库；剪辑可选 ChatCut、剪映无界面工具或已有剪辑器 | 区分内容规划与实际剪辑，先检查所选工具是否可用 |
| **5. 把视频、逐字稿和目标交给 AI** | 说明受众、用途、时长和想保留的内容 | 拆选题、组合问答、定位原话，执行已授权的剪辑 |
| **6. 精修并准备发布** | 检查成片，必要时在剪映里手动修改 | 按最终版本校准字幕，交付成片 → 封面 → 正文 → 标题 |

完整说明：[六步使用指南](docs/workflow.md) · [可直接复制的提示词](docs/prompts.md)

> 时间取决于录播长度、素材质量、电脑和所用工具。本仓库不承诺“任意视频十分钟完成”，也不保证流量、收入或涨粉效果。

## 安装

复制下面这段话，发给你正在使用的 AI：

```text
帮我安装这套「艾玛视频技能」：https://github.com/adoria111/emma-video-skills
```

有些 AI 只能聊天，不能帮你安装电脑上的工具。如果安装不了，让它说明需要换用什么应用，或参考下面的手动安装方法。只读完这个网页，不算安装成功。

需要 Python 3.10 或更新版本。先下载仓库，再选择你使用的宿主：

```bash
git clone https://github.com/adoria111/emma-video-skills.git
cd emma-video-skills

# 安装到 Codex 的用户技能目录
python3 scripts/install.py --app codex

# 或安装到 Claude Code 的用户技能目录
python3 scripts/install.py --app claude

# 或指定其他支持 SKILL.md 的宿主目录
python3 scripts/install.py --dest /path/to/skills
```

安装器默认不覆盖同名技能。如果本机已经有口播参谋或封面技能，先看差异；确实要换成公开版时加 `--replace`，旧目录会先备份到目标目录旁的备份文件夹。也可用 `--skill emma-video-workflow` 只安装一个技能；使用总入口的完整流程时建议装齐六个。

不想使用命令，可以把 `skills/` 里的各个完整文件夹复制到宿主的技能目录。安装后按宿主提示刷新技能或开启新对话。目录约定之外的宿主兼容性未逐一实测；封面生成、文件访问、剪辑和发布能力仍取决于宿主工具。

详见 [安装与更新](docs/install.md)。

## 小白怎么用

装好后，把视频、逐字稿或已有成片发给 AI，也可以告诉它文件在哪个文件夹。有字幕就一起提供，没有也可以先给视频。然后直接说你想做什么，不用记六个技能的名字。

想从视频一路做到发布材料，可以复制这句话：

```text
用艾玛视频技能处理这个视频，帮我剪出适合发小红书的片段，保留有用的观点和案例，去掉无意义的重复和停顿。做好视频和字幕，再配上封面、发布文案和标题。
```

### 除了完整剪辑，还能怎么用？

下面每句话都可以单独发给 AI；把对应素材一起交给它即可。

| 你现在想做什么 | 可以直接这样说 |
| --- | --- |
| 视频还没有逐字稿 | 用艾玛视频技能，把这个视频转成逐字稿和字幕，听不清的地方标出来。 |
| 直播太长，不知道剪什么 | 用艾玛视频技能，找出这场直播里值得单独发的选题，告诉我每条讲什么、原话在哪，先不剪视频。 |
| 自己剪，想要剪辑方案 | 用艾玛视频技能，帮我列出这条视频保留哪些、删哪些、按什么顺序放，我自己来剪。 |
| 几段回答想合成一条 | 用艾玛视频技能，把这些素材里关于同一个问题的回答和案例组合成一条视频，不相关的别硬凑。 |
| 只想去掉啰嗦的部分 | 用艾玛视频技能，删掉这条口播里无意义的重复和停顿，保留原意，给我新视频和同步字幕。 |
| 想知道成片哪里有问题 | 用艾玛视频技能，检查这条视频有没有答非所问、重复啰嗦或衔接不顺的地方，先给建议，不改视频。 |
| 自己剪过，字幕对不上了 | 用艾玛视频技能，按我最新剪好的视频校准字幕，不要再动视频内容。 |
| 已经检查好，只差导出 | 用艾玛视频技能，导出我刚检查过的最新工程，并给我匹配的字幕文件。 |
| 只缺封面 | 用艾玛视频技能，从这条成片里选一张清晰截图，做小红书上下双图封面，标题按视频内容提炼。 |
| 只想改一下已有封面 | 用艾玛视频技能，把这张封面的标题换成我给的新标题，其他保持原样。 |
| 视频做好了，不会写发布文案 | 用艾玛视频技能，按这条成片写小红书正文和标题，不要写进视频里已经删掉的内容。 |
| 长视频想加章节目录 | 用艾玛视频技能，给这条最终成片做带时间的章节目录，让观众方便找到想看的内容。 |
| 一批视频不知道先发哪条 | 用艾玛视频技能，按新观众容易看懂的顺序排列这些视频，说明理由，每条都要能独立看懂。 |

**[查看 14 种用法的完整示例：要给什么素材、怎么说、会得到什么](docs/prompts.md)**

只要其中一项，就直接说“这次只做字幕／封面／标题”。只给逐字稿也能做选题、剪辑建议和文字逻辑分析；实际转写、剪视频和做封面，需要当前 AI 有对应工具。剪辑可选 ChatCut、剪映等，见 [工具说明](docs/dependencies.md)。写好发布文案不等于已经发到平台。

## 手动去水词之后

如果你又在剪映里删了水词，**要以最新工程或新成片重新校准字幕**。视频变短了，不代表独立字幕轨和上方问题标题也自动变短。不要只在旧字幕里批量删除“然后、就是”。

把新版本交给 AI，说明“只校准字幕，不再动视频”，然后在最终检查后要求导出。具体流程见 [字幕和版本同步](docs/subtitle-sync.md)。
