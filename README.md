# 艾玛视频 Skills

**把一场直播或线上课，整理成可以发布的视频、字幕、封面和文案。**

这套 Skills 整理了录播拆选题、口播剪辑、二次剪辑后的字幕校准，以及小红书双图封面的制作方法。可以从总入口连续做，也可以只调用其中一项。

它们是给 AI 助手使用的工作说明和少量辅助脚本。安装 Skill 不等于安装剪辑引擎，也不意味着 AI 已经获得你电脑、图片工具或发布账号的操作能力。

## 按这六步开始

| 顺序 | 你要做什么 | AI / Skills 做什么 |
| --- | --- | --- |
| **1. 开直播或线上课** | 录下分享、演示和问答；保留有权使用的素材 | 这一步主要由你完成，不要求重新写一份标准口播稿 |
| **2. 导出录屏或视频切片** | 保存原录播或已有切片，文件名能分清来源 | 检查素材与版本，避免把重复切片当成新内容 |
| **3. 导出逐字稿** | 可用得到大脑、剪映或已有转写工具导出 TXT / SRT | 有匹配字幕就复用；没有时可用本地转写辅助脚本 |
| **4. 安装 Skills 和剪辑能力** | 安装本仓库；需要无界面剪映时另装上游依赖 | 区分内容规划与实际剪辑，先检查工具是否可用 |
| **5. 把视频、逐字稿和目标交给 AI** | 说明受众、用途、时长和想保留的内容 | 拆选题、组合问答、定位原话，执行已授权的剪辑 |
| **6. 精修并准备发布** | 检查成片，必要时在剪映里手动修改 | 按最终版本校准字幕，交付成片 → 封面 → 正文 → 标题 |

完整说明：[六步使用指南](docs/workflow.md) · [可直接复制的提示词](docs/prompts.md)

> 时间取决于录播长度、素材质量、电脑和所用工具。本仓库不承诺“任意视频十分钟完成”，也不保证流量、收入或涨粉效果。

## 安装

需要 Python 3.10 或更新版本。先下载仓库，再选择你使用的宿主：

```bash
git clone https://github.com/adoria111/emma-video-skills.git
cd emma-video-skills

# 安装到 Codex 的用户技能目录
python3 scripts/install.py --app codex

# 或安装到 Claude Code 的用户技能目录
python3 scripts/install.py --app claude

# 或指定其他支持 SKILL.md 的宿主目录
python3 scripts/install.py --dest /path/to/skills
```

安装器默认不覆盖同名技能。如果本机已经有口播参谋或封面技能，先看差异；确实要换成公开版时加 `--replace`，旧目录会先备份到目标目录旁的备份文件夹。也可用 `--skill emma-video-workflow` 只安装一个技能；使用总入口的完整流程时建议装齐六个。

不想使用命令，可以把 `skills/` 里的各个完整文件夹复制到宿主的技能目录。安装后按宿主提示刷新技能或开启新对话。目录约定之外的宿主兼容性未逐一实测；封面生成、文件访问、剪辑和发布能力仍取决于宿主工具。

详见 [安装与更新](docs/install.md)。

## 第一条提示词

```text
用 $emma-video-workflow 处理我提供的直播切片和匹配逐字稿。

目标：把我的经验整理成适合新观众观看的视频，用于介绍课程。
请完整阅读素材，按相近问题组合，不凑数量。
每条暂按 5—8 个问答、5—10 分钟尝试；内容不适合时说明原因并调整。
保留能帮助观众理解的提问和案例，只清理无信息的重复、停顿与口癖。

请连续交付成片及同步字幕、对应视频截图制作的封面、发布正文和标题。
保留原素材和可编辑工程；发布文案供我审核，不直接发到平台。
```

这里的问答数和时长只是一个示例，不是所有视频都要遵守的规则。只想做标题、字幕或封面时，直接说具体任务。

## 手动去水词之后

如果你又在剪映里删了水词，**要以最新工程或新成片重新校准字幕**。视频变短了，不代表独立字幕轨和上方问题标题也自动变短。不要只在旧字幕里批量删除“然后、就是”。

把新版本交给 AI，说明“只校准字幕，不再动视频”，然后在最终检查后要求导出。具体流程见 [字幕和版本同步](docs/subtitle-sync.md)。
