# 可复制提示词

文件位置、受众和目标改成你自己的即可。不需要把所有模板同时发给 AI。

## 一次处理完整素材

```text
用 $emma-video-workflow 处理这些录播／直播切片及匹配逐字稿。
受众：[给谁看]
用途：[分享经验／课程介绍／访谈精华等]
偏好：[时长、比例、风格；没有则合理判断]

完整阅读后按主题组合，保留有用的问答和具体例子，不凑数量。
先检查现有工具，在已经授权的范围内完成剪辑。
连续交付成片及同步字幕、对应视频帧制作的封面、发布正文和标题。
保留原素材及可编辑工程。文案供我审核，不直接发布。
```

## 只拆选题

```text
用 $koubo-advisor 把这份逐字稿拆成能独立成片的选题。
每条给核心问题、来源片段、首尾原话、建议顺序和标题。
没有时间码就给原话定位，不要猜秒数。这次先不剪视频。
```

## 我已经在剪映里去过水词

```text
我对这一版视频做了去水词，当前工程是最新版本。
用 $video-edit-handoff 对照保留下来的口播校准字幕，
删掉原声已经剪走的词，重算字幕、问题题签、片尾提示和章节时间。
不要再改我的视频切口。保留原工程，完成后给我可检查的校准副本。
```

## 检查完以后导出

```text
我检查完了，请导出刚才检查过的最新工程。
不要使用检查前的旧快照。同步给我这一版的 SRT 和章节时间。
原版本保留，说明实际导出文件的位置和检查结果。
```

## 做同款双图封面

```text
用 $xhs-double-photo-cover 给这些最终成片做同系列封面。
每条从它自己的成片选清晰视频帧，上下复制同一张图。
参考我提供的样式：3:4竖版、整幅暗底、纯白宋体大字、柔和黑影。
标题根据各自成片提炼；不要把参考图的人物或上一条标题带过来。
保留底图及旧版，直接检查成图后交付。
```

## 只写发布文案

```text
用 $video-publish-pack，根据这份最终成片及匹配字幕，
写适合[平台]的正文、一个主标题和必要的章节目录。
我的行动引导是[看主页课程介绍／评论提问／不需要引导]。
只使用成片实际保留的信息，不编造收益、成绩或课程承诺。
```
