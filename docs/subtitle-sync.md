# 手动剪辑后，让字幕重新对应视频

常见情况：视频主轨已经去掉停顿和水词，但独立的字幕、问题题签和片尾提示仍在原来的时间位置。此时只修改文字，后半段仍会错位。

## 以哪个版本为准

优先使用用户刚刚检查过的最新工程；没有工程时，使用明确指定的新成片。文件的修改时间只能帮助查找，不能独立决定哪个版本权威。若工程中仍有未保存修改，先正常保存；避免文件写入与编辑器同时修改同一工程。

## 需要做的三件事

1. **确认保留下来的声音。** 有剪辑源区间时建立源时间到新时间的映射；必要时转写新口播，复核术语和被剪断的句子。不能对字幕全文无差别删除“然后、就是”，因为这些词有时仍有语义作用或仍在原声里。
2. **同时校准内容和时间。** 删除原声已消失的词；保留实际说过的核心表达。重新计算每条字幕的起止，并同步问题题签、章节、片尾提示。字幕不互相重叠，不超出成片结尾；检查可读性和关键剪切接口。
3. **只修改授权范围。** 用户只要求校准字幕时，不再剪视频、不改变速度或音量。保留原工程，采用工具支持的副本方式交付，并核对视频片段与原版一致。

## 导出前后

用户检查后再导出时，重新读取最新工程，导出它的稳定快照。上次准备的快照不自动包含用户后续修改。

先检查导出是否完整，再查看实际画面、字幕位置和片尾；按需要检查音频。完整解码、帧数一致、转写复核和人耳试听是不同证据，不能互相替代。没有完成的检查明确说明，不写“全片验收通过”。

配套 SRT、逐字稿和章节应从这次导出的同一版生成；旧成片及其字幕单独保留。封面标题和发布文案也应对照新版本，不能继续承诺已经被删掉的内容。
