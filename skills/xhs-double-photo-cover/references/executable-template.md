# 可执行双图封面模板

用户选择确定性排版、且宿主允许使用本地脚本时，可运行 [render_cover.py](../scripts/render_cover.py)。这是本机 Pillow 模板：不联网、不上传素材、不下载字体，不改变人物；需要 Python 3.10+ 和 Pillow。先复用已有环境，缺少依赖时按当前授权安装 `Pillow>=10`。字体使用本机有权使用的粗宋体／明体，不随包分发。

它固定 1080×1440、同一半幅复制两次、中性压暗、同字号两行白字和柔和投影。**不自动识别人脸，不自动选帧，也不保证模仿参考图的全部视觉细节。** 模型仍需看素材、选字形和判断构图。

## 1. 看图后填写配置

从本次成片或可映射的原素材取得清晰底图。先查看底图和 [已确认参考](approved-cover.png)，再写工作目录中的 `cover-config.json`。相对路径以配置文件所在目录为基准；不要把私人配置或成图提交到公开仓库。

以下仅说明格式，坐标须按本次图片重选，不能照抄。坐标采用自动纠正 EXIF 方向后的原图像素，四项均为 **左、上、右、下**，不是宽高。

```json
{
  "source": "frame.png",
  "crop": [0, 270, 1080, 990],
  "subject_box": [150, 330, 920, 970],
  "face_boxes": [[330, 490, 630, 770]],
  "font": "chosen-songti.ttf",
  "font_index": 0,
  "titles": ["想写短剧？", "入行5个问题"],
  "darkness": 0.48,
  "line_centers": [585, 795]
}
```

- `crop`：手选 3:2 横向区域。脚本拒绝越界和错误比例，避免暗中拉伸或居中裁切。
- `subject_box`：实际需要保留的完整头部及可见肩部区域，必须在裁切框内；不能为了通过检查故意缩成只框住脸。素材无法容纳时回原素材换取景，或说明需要其他布局。
- `face_boxes`：框住所有人物的眼睛、鼻子和嘴，可用一个稍宽的矩形包住一张脸的这些区域。脚本将它复制到下半幅，并加 12px 留白检查文字碰撞。不是自动人脸检测；框错或漏框时检查无效。
- `font` / `font_index`：字体文件及 TTC 字体集合索引。不要根据字体名称猜字重；渲染后检查粗竖细横、中文缺字和标点。
- `titles`：恰好两行。默认字号范围 130—190，两行同字号；长句不能排下会报错，优先缩短未锁定文案，不通过拉伸、极小字号硬塞。可在确有需要时设置 `min_font_size` / `max_font_size`，但仍须看缩略图。
- `darkness`：黑色蒙版强度，0 不压暗、默认 0.48。根据原图明暗调整。
- `line_centers`：两行文字可见字形的垂直中心，分居接缝 720 上下。出现五官碰撞时调整裁切或标题位置；不能通过缩小五官框骗过检查。

## 2. 先生成并查看裁切预览

在技能目录执行（或使用脚本绝对路径）：

```bash
python3 scripts/render_cover.py prepare --config /path/to/work/cover-config.json --out /path/to/work/preview-v1
```

实际查看 `panel.png`、`face-regions.png` 和 `plain-cover.png`：头肩是否完整、有无过量空墙、五官区域是否标对。配置错误就修正并生成新的预览目录。**不要把准备和渲染合成一个不看图的连续命令。** 这是 AI 的内部检查，不要求用户每一步批准。

`plan.json` 保存配置、原图／字体／半幅校验值，便于追溯。原图只在准备阶段读取；渲染使用已保存半幅。它们是工作文件，包含本机路径，不应公开分享。

## 3. 生成封面并实际看图

```bash
python3 scripts/render_cover.py render --prepared /path/to/work/preview-v1 --out /path/to/work/render-v1
```

输出：

- `cover.png`：成图，1080×1440。
- `thumbnail.png`：270×360 手机缩略预览。
- `background.png`：相同压暗半幅复制两次的底图，便于核对裁切。
- `render.json`：字体、字号、位置及几何检查结果，**视觉状态固定为待查看，不自动宣称通过**。

脚本拒绝覆盖任何已有输出目录；修改后使用 `preview-v2`、`render-v2` 等新目录，保留前版。文字越界、行间重叠或碰到标注五官会报错，且不会创建成图目录。半幅或字体被替换后须重新准备。

按照 [视觉检查](visual-style.md) 查看成图和缩略图，并将参考缩到相同宽度对照。指出实际看到了什么，而不是复述参数。如果工具无法看图，报告“已生成，视觉未验证”；不能仅凭脚本成功声称观感合格。只交付最终成图、必要预览与保存位置，无需让小白理解配置文件。

模板只处理这套默认双图布局。若用户指定单图、特殊文字位置，或素材无法兼顾头肩与大字，按当前需求换布局，不强行通过检查。Pillow 的字体与绘图接口见 [官方文档](https://pillow.readthedocs.io/en/stable/reference/ImageDraw.html)。
