# 视频转写

先检查用户提供的文件和已授权素材目录，不要求用户重复上传已经能找到的文件。按本次目标选择输入：

- 有同版本 SRT / VTT：抽查开头、中段和结尾的文字与时间是否匹配视频；可用就复用，局部错误只做局部核对或校准。
- 只有 TXT：可直接做选题、内容整理和文字逻辑分析；需要精确剪辑或字幕时，再补可靠时间定位，不按字数猜秒数，也不一律重转整段视频。
- 只有音视频：这是正常输入，检查可用转写能力后继续。可以简短提醒“有同版字幕能节省时间”，但不把用户补交字幕作为开工条件。

来源不同或用户已重剪时，旧字幕只能作为文字参考，不能直接沿用时间。用户明确要求重新转写时，按其要求执行。

## 本地执行

本技能包含自行编写的 [转写脚本](scripts/transcribe_local.py)，依赖另行安装的 `faster-whisper`。

```bash
python3 scripts/transcribe_local.py /path/to/video.mp4 \
  --output-dir /path/to/new-output --model small --language zh
```

这里的脚本路径以本技能目录为基准。先检查当前宿主已有的转写能力；工具满足目标时可复用，不必为了使用附带脚本再装一套依赖。选用本脚本时，确认实际运行的 Python 环境、`faster-whisper` 是否可导入及模型是否可用；“安装完成”或“发现缓存目录”都不等于转写已通过。

需要安装或修复依赖时，在已有授权和宿主权限内执行并说明用途，优先隔离环境，避免改坏其他任务的依赖。运行环境首次配置或发生变化时，先用一小段有清晰人声的素材验证模型加载、实际识别和输出，再处理长视频；短片可直接运行，已有成功记录的同环境无需每次重复试跑。

默认只使用缓存模型。已确认有与当前转写引擎兼容、文件完整的本地模型目录时，可用 `--model /path/to/model-directory` 指定它；不能把任意 Whisper 缓存都当作可用模型。首次需要下载时明确使用 `--allow-model-download`，该开关只允许获取模型，媒体仍在本机处理。

输出 TXT、SRT、含逐词时间的 JSON。输出目录必须不存在，保留原文件。没有本地引擎且用户已选用其他转写能力时，遵循那个工具的要求，不把此脚本说成已运行。

## 转写失败时

- 保留实际运行命令、错误输出和相关依赖版本。区分模型缺失、访问网络失败、接口不兼容和媒体读取失败，不凭“转写失败”就断言某两个版本冲突。
- 错误指向模型查找或下载环节，且已有兼容的完整本地模型时，可尝试指定本地目录；这不是所有依赖错误的通用修复。
- 确认是依赖接口问题后，再根据完整错误及官方兼容说明，在隔离环境中调整相关依赖并复验；不要连续盲目升级、降级或重复安装。
- 只有新证据或有明确依据的修复方法才重试。修复仍不可行时，说明卡在哪一步及最少缺什么；可复用已有字幕，或在授权内改用另一项可用转写能力。不要擅自上传媒体或切换付费服务。
- 原因未确认就标为待核实。继续完成不依赖转写的部分；没有可靠文字和时间时，不编造字幕、内容结论或精确剪辑位置。

## 内容校对

- 核对姓名、行业词、平台名、数字及近音词，必要时结合原声和上下文；听不清的地方标明不确定，不补造事实。
- 多人声音、播放素材和广告须区分来源。无法可靠分辨说话人时，不虚构说话人标签。
- 自动转写时间是定位依据，不等于已经检查过音画切口；零长度词、尾音和接缝需单独核对。
- 用户只要逐字稿时，不顺手改观点、生成新口播或执行剪辑。

若任务是“去水词后重新同步字幕”，交给 `video-edit-handoff` 处理新时间映射；不要仅清理原稿文字后交回原时间轴。

交付说明输入版本、文件位置、转写方式及关键未确认词。不得把机器识别初稿标成逐秒人工听审结果。
