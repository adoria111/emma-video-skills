# 视频转写

先检查用户是否已有与指定音视频相匹配的 TXT、SRT 或 VTT。有可用文本就复用，不为走流程重复转写。来源不同或用户已重剪时，旧字幕只能作为文字参考，不能直接沿用时间。

## 本地执行

本技能包含自行编写的 [转写脚本](scripts/transcribe_local.py)，依赖另行安装的 `faster-whisper`。

```bash
python3 scripts/transcribe_local.py /path/to/video.mp4 \
  --output-dir /path/to/new-output --model small --language zh
```

这里的脚本路径以本技能目录为基准。使用含依赖的 Python 环境；先检查已有安装，不静默安装或切换到付费服务。默认只使用缓存模型；首次需要下载时明确使用 `--allow-model-download`。该开关只允许获取模型，媒体仍在本机处理。

输出 TXT、SRT、含逐词时间的 JSON。输出目录必须不存在，保留原文件。没有本地引擎且用户已选用其他转写能力时，遵循那个工具的要求，不把此脚本说成已运行。

## 内容校对

- 核对姓名、行业词、平台名、数字及近音词，必要时结合原声和上下文；听不清的地方标明不确定，不补造事实。
- 多人声音、播放素材和广告须区分来源。无法可靠分辨说话人时，不虚构说话人标签。
- 自动转写时间是定位依据，不等于已经检查过音画切口；零长度词、尾音和接缝需单独核对。
- 用户只要逐字稿时，不顺手改观点、生成新口播或执行剪辑。

若任务是“去水词后重新同步字幕”，交给 `video-edit-handoff` 处理新时间映射；不要仅清理原稿文字后交回原时间轴。

交付说明输入版本、文件位置、转写方式及关键未确认词。不得把机器识别初稿标成逐秒人工听审结果。
