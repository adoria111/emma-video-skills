# 视频剪辑与字幕衔接

先确认任务是新剪辑、只校准字幕，还是导出已检查工程。检查指定素材、最新工程和已安装工具，选择能完成本次目标的最小操作范围。

本技能独立说明交接方法，不包含第三方剪辑代码。用户选用无界面剪映时，调用已经合法安装、环境检查通过的 `yichen-jianying-edit`，按该工具当前文档执行。外部来源和许可见 [依赖说明](https://github.com/adoria111/emma-video-skills/blob/main/docs/dependencies.md)。不能把本仓库的 MIT 许可当成外部剪辑器的商用授权。

## 新剪辑

- 按明确的源区间、首尾原话和目标顺序执行；只有粗略逐字稿时先完成可靠定位。
- 保留原素材与现有工程；使用工具支持的隔离副本或快照，不用运行中的旧工程文件覆盖用户刚做的修改。
- 清理口癖要判断语义，“这就是原因”不能因含有“就是”而被整句机械删除。
- 音画与字幕使用同一剪辑映射，检查尾音、半个词、声音爆点和上下句指代。
- 用户未要求加速、配乐、滤镜时，不自行加入这些处理。

## 用户已经手动去水词或重排

1. 确认用户指定的新版本，正常保存必要修改。需要关闭编辑器才能读取时，按工具约束正常退出，不强制结束进程；能够由助手完成的常规保存操作无需再次索要已有授权。
2. 检查视频、字幕轨和题签各自的结束时间，识别是否仍在旧时间轴。
3. 读取真实剪辑区间建立映射；必要时对新口播转写，核对被删除的词和术语。只按时间整体压缩 SRT 或全文删除某个词都不可靠。
4. 同时更新字幕文字、起止时间、问题题签、片尾提示和章节目录。字幕不得超出成片结尾或互相重叠；避免单句过长遮脸。
5. 用户只要字幕校准时，视频片段、切口、速度、音量保持原样，并验证一致性。不能为了让字幕通顺而补造原声中没有的话。

## 用户检查后要求导出

重新核对最新保存工程。导出源必须包含用户的检查后修改，不能沿用较早的冻结快照。保留已检查源工程，从工具支持的稳定输入导出，并同步这一版的 SRT、逐字稿和章节。

工具执行失败时保留诊断；先查询输出状态，只有新的证据或明确可解决问题的方法才重试。不通过丢字幕、删效果、换旧快照来掩盖失败。

## 验证与状态

- 检查输出时长、画幅、帧率、帧数及完整解码，按工具的实际时间精度验收。
- 查看实际开头、关键拼接、代表性字幕和片尾。涉及声音修改时检查声音与切口。
- 解码通过不等于内容和听感都通过；自动转写不等于人耳试听。不要扩大检查结论。
- 分清“副本已生成”“首页已登记”“编辑器保存并重开”“MP4已导出”。只交付孤立工程 JSON 不能声称资源齐全、可继续编辑。

完整制作按成片及字幕、封面、正文、标题继续交接；只导出用户已经检查的版本时，更新受影响的配套文件即可，不重新策划或重做封面。
