# 口播精剪：清理重复与口误，保留自然表达

用户要求“精剪口播”“去水词”“删重复和停顿”，或完整制作任务包含这些要求时使用。只做分析时给建议；只校准字幕时不借此重新剪视频。已有明确授权的精剪直接执行，不逐个口癖重复索要确认。

## 先理解片段，再决定顺序

先弄清每段承担什么作用：提出问题、交代背景、给出判断、举例或补充限制。按观众能理解的逻辑组合，不因拍摄时间或文件顺序就直接拼接；补录的开头可能应放在前面。

重排不是默认必做。原顺序已经清楚时保留；用户只授权局部精简时不改整体结构。跨段组合要保留问题与回答、指代对象、时间关系和必要背景，不把后来发生的事拼成前因，也不把不同人的经历合成一人的陈述。

## 四类精剪判断

| 情况 | 可以清理什么 | 应保留什么 |
| --- | --- | --- |
| 重复表达／多次录制 | 同义反复、同一段的多次试录、没有新增信息的复述 | 解释同一观点的不同有效例子、重要限定、递进、强调和必要的情绪重复 |
| 说错后重说 | 明确废弃的错误说法、重新起句前的准备过程 | 准确完整的版本；内容本身在分析错误、比较前后观点时，保留有意义的纠正过程 |
| 口癖与犹豫 | 在该句中确实没有信息、可以自然移除的填充音或词 | 语义、逻辑连接、态度、必要的互动和人物语气 |
| 停顿与空白 | 无信息等待、明显拖长且影响理解的气口 | 正常换气、句间层次、用于强调或表达情绪的停顿 |

### 多个版本怎么选

优先保留**含义准确、信息完整、表达流畅且能接上前后文**的版本。最后一遍经常是重录完成版，但时间靠后不是质量证明；不能不比较就默认删掉前面的全部表达。信息等价、质量相当时，可选择较后且录制状态更好的版本。

不同版本各有必要信息时，保留互补部分并检查衔接。数字、对象、时间或结论互相冲突时，查看上下文是否明确纠正；无法确定就标出冲突，不靠拼接替用户决定事实。

### 不按词表机械删除

“不是”“重来”“我重新说一下”等若属于试录准备过程，可以随废弃片段清理；若是论证中的否定、反驳或重要转折，应保留。“就是”“然后”等同样先判断功能。例如“这就是原因”里的“就是”和交代事件先后时的“然后”，不能只因命中词表就删。

字幕可能已省略口癖，而原声仍然说了。需要处理原声时回到音频定位，不能仅删除字幕文字就声称已经去水词。

## 切口与节奏

- 优先利用句子边界和自然停顿；句内删除口癖时保护相邻发音、尾音与必要呼吸。识别时间只是候选边界，不机械照切零长度词或不完整词尾。
- 空白只压缩到听起来自然，不统一删到零，不强制每个间隙相同时长，也不以总时长越短作为质量指标。
- 删除造成残字、吞音、语气突兀或明显画面跳切时，调整边界、选择更完整的替代说法，或保留这处自然停顿／填充。不要为了证明“删得干净”牺牲表达。
- 保持音画共同剪切；不要只移动声音造成口型错位。未要求加速、配乐或额外效果时，不用这些处理掩盖生硬接口。

## 完成后看什么

1. 按新顺序通读内容：每个问题是否有答案，指代和编号是否有前文，案例、否定、限制条件及标题承诺是否仍成立。
2. 回听并查看改动接口附近的上下句，确认没有半个词、异常断气、爆点或突兀切换。自动转写和波形只能辅助，不能冒充实际试听；无法试听时说明具体未验证项。
3. 依据同一组保留区间重建字幕时间，同步题签、章节和片尾。确认字幕对应的是剪后原声，不是修剪前的文字或旧时间。
4. 保留原素材和可恢复版本，交付用户指定范围内的成片与配套文件。存在未解决的内容冲突或切口问题时据实说明，不把“文件已导出”当作全部检查通过。

必要时记录关键取舍及素材位置，便于复核；不要求为每一个普通删除动作建立额外台账。
