# 矮马口播样式：4:3 满幅人物与灰底字幕

用户要求“用矮马口播样式”“沿用这套构图和字幕”，或已明确采用本预设时读取。它是作者用过的一套口播参考，不是所有视频都必须采用的格式；当次指定的画幅、样式和参考片优先。

## 画面是什么样

- **视频是 4:3 横向画布**，人物画面铺满，保留自然的头部、肩部和必要环境，不拉伸人物。
- **字幕水平居中、靠近画面下方**，清晰白字配黑描边，下方垫半透明深灰底，背景宽度随字幕长度变化。
- **封面单独制作**：3:4 竖幅、上下双图、暗底白宋体属于封面样式，不把视频也做成上下双图，不把视频字幕自动改成封面字体。

## 套用到新素材

1. 查看代表性画面。人物位置、源画幅不同就重新裁切与平移；有课件、演示或连麦画面时保护必要内容，不为人物满幅裁掉信息。
2. 用一条短字幕、一条长字幕及有必要画面信息的片段试排。文字不遮住脸、嘴或关键课件，不超出边缘；字幕按语义拆分，不靠压扁字形塞进一行。
3. 同一条视频保持字幕字形、大小、底色和位置一致。若需要上方问题题签，另设层级并避开主体，不把题签和逐句字幕混成一轨；原参考没有要求所有视频必须加题签。
4. ChatCut 或其他工具采用可用的对应设置，检查实际成图。只有成片而无工程时，字号和坐标只能作视觉估计；不承诺跨工具像素级一致。
5. 版式核对后用于全片，并从导出视频抽查长短字幕、人物移动和片尾。用户只要求换样式时，保留口播内容、剪辑顺序和时间；发现字幕不同步另行按任务范围处理。

## 字幕文件与可编辑样式

普通 SRT 主要保存文字和时间，不能单靠它保留这套灰底、位置和字体样式。需要成片呈现样式时，在编辑器中应用并导出；需要之后继续修改样式时，保留对应可编辑工程及资源。不能把一份 SRT 称为已经交付完整字幕包装。
