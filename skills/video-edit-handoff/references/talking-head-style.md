# 矮马口播样式：4:3、3:4、9:16 构图与字幕

用户要求“用矮马口播样式”“沿用这套构图和字幕”，或已明确采用本预设时读取。核心是人物取景和清楚的字幕层级，不是强制改成某个比例；当次指定的画幅、样式和参考片优先。已有满意成片就保留其画幅；未指定时依据源素材与用途选择，不把所有竖片改为 4:3。

## 画面是什么样

- **视频可用 4:3、3:4 或 9:16**，围绕人物的头部、肩部与必要环境取景，减少多余空墙和天花板，不拉伸人物。
- **字幕水平居中、靠近画面下方**，清晰白字配黑描边，下方垫半透明深灰底，背景宽度随字幕长度变化。
- **封面单独制作**：3:4 竖幅、上下双图、暗底白宋体属于封面样式。视频本身也可以是 3:4，但不因此做成上下双图，不把视频字幕自动改成封面字体。

## 不同画幅怎么调整

| 视频画幅 | 常用画布示例 | 人物与字幕的处理 |
| --- | --- | --- |
| 4:3 横向 | 1440×1080 | 人物满幅，保留头肩和必要环境；字幕靠下，采用下方原参考灰底样式 |
| 3:4 竖向 | 1080×1440 | 从较长竖片中去掉多余上下空间，再平移取景；让人物在画面中更突出，不能只改输出尺寸而保留大块天花板 |
| 9:16 竖向 | 1080×1920 | 保留竖向表达需要的上半身或动作空间；人物偏下、顶部过空时，适量等比放大并上移画面，重新安排字幕与人物的关系，不拉伸或强裁成 4:3 |

先看人物在源画面哪里，再决定裁切框和移动量；不是固定把原画面中心对准新画布中心。缩放后检查画布边缘是否露空、额头和下巴是否被切、手势或课件是否丢失。源画幅相同，也可能因为机位和人物位置不同而需要不同参数。

连麦／分屏素材单独处理：讲者独立讲解时可以裁出讲者区域；另一人的提问、反应或共享内容是理解所必需时，保留相应画面或切换取景，不整段强制使用单人大幅放大。

## 4:3 原参考参数

下表来自作者已留存的口播工程样式记录。原生字段用于同类剪映工程复现，不是所有软件都通用的单位；公开版只保留样式参数，不包含原视频、人物截图或私人路径。

| 项目 | 参考设置 | 复用方式 |
| --- | --- | --- |
| 视频画布 | 1440×1080，4:3；原参考为 30fps | 用作这一预设的起点；帧率按素材与交付目标确定，不为套样式无故改变原帧率 |
| 人物缩放 | 约 133.0166% | 原片的裁切起点；新素材先检查人物是否完整，不能机械放大 |
| 人物位置 | 剪映原生 x≈0.15677，y=0 | 仅适用于原片及对应坐标体系；其他素材以画面构图为准 |
| 字幕颜色 | 白字、黑描边 | 在明暗不同的画面上都检查可读性 |
| 字幕大小与描边 | 原生内部字号 5.5，描边参数 0.08 | 不等于 5.5px、5.5pt 或其他软件字号；跨工具按实际渲染效果匹配 |
| 字幕位置 | 原生 x=0，y=-0.875 | 原 1080 高画布中，字幕中心距底部约 67.5px，即画面高度的 6.25% |
| 字幕底色 | `#232323`，不透明度约 52.93% | 深灰半透明底，随字幕长度变化，不做整幅固定横条 |
| 底色样式 | 原生背景样式 2，圆角参数 0.3 | 属于原生字段；其他工具用相近视觉效果实现，不照抄字段值 |

**67.5px 是字幕中心到画面底部的距离，不是文字底边的安全距离。** 多行或更大字号会占用更多高度；需根据实际文字边缘和发布界面遮挡调整，不能把这组数值当作所有平台的安全区标准。

## 3:4 已用工程的参考值

以下来自一次 1080×1920 直播素材转为 1080×1440 成片的制作记录，原成片为 24fps。它们是该批素材的实现记录，不是与 4:3 通用的一套坐标，也不是本技能的强制默认值。

| 场景 | 原生参数记录 | 使用边界 |
| --- | --- | --- |
| 单人口播 | scale≈1.333333，x=0，y≈0.333333 | 在该工程中放大并调整人物位置，减少源片的多余顶部空间；新素材重新看图 |
| 连麦中突出讲者 | scale≈2.7，x≈1.0125，y≈0.05 | 只适用于该分屏的讲者区域；其他人的位置不同就重新裁切 |
| 保留提问者画面 | scale≈1.333333，x=0，y≈0.10 | 该批次提问片段采用单独取景，避免把提问者直接裁没 |
| 逐句字幕 | x=0，y≈-0.78，内部字号 6.5，白字黑描边，描边 0.07 | 原片的下方字幕设置；不是像素字号。该批记录未设置灰底，若本次选灰底样式需另行应用 |
| 上方问题题签 | x=0，y≈0.83，内部字号 6.3，白字黑描边，描边 0.06 | 概括当前问题并随内容变化；有题签时预留空间，不与头部挤在一起 |

以上 x/y、scale 与内部字号都属于原工具坐标和缩放体系。另一工具的正负方向、适配画布方式可能不同，必须看实际渲染；不要把 133% 理解为在任意源文件上缩放相同倍数就必然得到同样构图。

## 9:16 与跨画幅的字幕适配

9:16 不沿用其他画幅的固定字幕坐标。本参考尚未记录一组独立核对过的 9:16 原工程数值，按以下方法适配，不把推算值标成历史参数：

- 先调整人物，再放字幕。避免人物仍缩在下半画面，上半幅都是空墙，而字幕又横在脸或胸前的关键动作上。
- 以画面可用宽度、每行字数与手机观看大小确定字号；改画布后重新试排长短句，不把 4:3 的内部字号直接照搬。
- 字幕保持水平居中，在下方可读区域定位；结合目标发布界面的控件和说明区留出空间，不能固定贴底，也不能把一个 `lower_third` 预设当作已匹配参考。
- 采用灰底版时沿用白字、黑描边、半透明深灰底的视觉关系，底框随文字变化；背景、字体和位置都要看最终压制结果。
- 有上方题签时，检查题签、头部和字幕三者的间距。若素材没有足够空间，先精简题签或调整排版，不为塞标题过度缩小人物。

## 套用到新素材

1. 查看代表性画面。人物位置、源画幅不同就重新裁切与平移；有课件、演示或连麦画面时保护必要内容，不为人物满幅裁掉信息。
2. 用一条短字幕、一条长字幕及有必要画面信息的片段试排。文字不遮住脸、嘴或关键课件，不超出边缘；字幕按语义拆分，不靠压扁字形塞进一行。
3. 同一条视频保持字幕字形、大小、底色和位置一致。若需要上方问题题签，另设层级并避开主体，不把题签和逐句字幕混成一轨；原参考没有要求所有视频必须加题签。
4. ChatCut 或其他工具采用可用的对应设置，检查实际成图。只有成片而无工程时，字号和坐标只能作视觉估计；不承诺跨工具像素级一致。
5. 版式核对后用于全片，并从导出视频抽查长短字幕、人物移动和片尾。用户只要求换样式时，保留口播内容、剪辑顺序和时间；发现字幕不同步另行按任务范围处理。

## 字幕文件与可编辑样式

普通 SRT 主要保存文字和时间，不能单靠它保留这套灰底、位置和字体样式。需要成片呈现样式时，在编辑器中应用并导出；需要之后继续修改样式时，保留对应可编辑工程及资源。不能把一份 SRT 称为已经交付完整字幕包装。
